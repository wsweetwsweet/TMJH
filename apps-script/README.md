# TMJH 訂餐站（免登入版）

同學打開網址就能點便當或飲料，不需要登入。訂單會自動存進你的 Google 試算表。

- `Code.gs`：後端程式（存資料、辨識菜單）
- `Index.html`：網頁畫面

## 架設步驟（約 10 分鐘，只要做一次）

1. **建立試算表**：到 Google 雲端硬碟新增一份 Google 試算表，命名為「TMJH 訂餐」。
2. **打開 Apps Script**：在試算表上方選單點「擴充功能 → Apps Script」。
3. **貼上程式**：
   - 把左邊預設的 `程式碼.gs`（或 `Code.gs`）內容全部刪掉，貼上本資料夾的 `Code.gs`。
   - 點左邊「檔案」旁的 **＋ → HTML**，名稱輸入 `Index`（不用打 .html），把內容全部換成本資料夾的 `Index.html`。
   - 按儲存（磁碟圖示）。
4. **開啟照片辨識**：點左邊「服務」旁的 **＋**，選「Drive API」→「新增」。
   這是 Google 雲端硬碟內建的文字辨識，免費，不需要任何金鑰。（沒開也能用，只是只能貼上文字或手動輸入菜單。）
5. **設定管理密碼**：點左邊齒輪「專案設定」，拉到最下面「指令碼屬性 → 新增指令碼屬性」，
   屬性填 `ADMIN_PASSWORD`，值填你自己訂的管理密碼。
6. **部署成網站**：右上角「部署 → 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   
   按「部署」，第一次會要你授權（選自己的帳號 → 進階 → 前往專案 → 允許）。授權內容包含試算表和雲端硬碟，因為辨識照片時會在你的雲端硬碟暫存一份文件，辨識完會自動丟到垃圾桶。
7. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`），這就是要給大家的點餐網址。

## 使用方式

- **管理員**：打開網址 → 「菜單管理」→ 輸入密碼 → 上傳菜單照片 → 開始辨識 → 核對品項價格、修改升級選項 → 儲存。
  - 照片辨識是用一般文字辨識加上規則猜品名和價格，**常會有錯字、漏項或分類不對**，儲存前一定要對照菜單檢查。
  - 也可以展開「或貼上菜單文字」，一行一個品項貼上，例如「排骨便當 90」、「紅茶 M30 L40」、「加珍珠 10」。
  - 想要更準：把菜單照片丟給 Claude 聊天（用你平常的 claude.ai 帳號，不需要 API），請它「整理成一行一個品項＋價格」，再把結果貼進來。
- **點餐的人**：打開網址就能選品項、選升級選項、填姓名送出。點錯了可以在同一台裝置上自己刪除。
- **統計**：「訂單統計」頁有叫餐清單（可一鍵複製給店家）和每個人應付的金額。也可以直接打開試算表的「訂單」工作表查看或列印。

## 之後修改程式

改完 `Code.gs` 或 `Index.html` 後，要「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選『新版本』→ 部署」，網址不會變。

## 注意事項

- 如果用的是學校的 Google Workspace 帳號，「誰可以存取」可能沒有「所有人」這個選項（學校管理員限制）。這時請改用個人 Gmail 帳號架設。
- 網址知道的人都能點餐，請只分享在班級群組裡。
- 價格會在伺服器端重新計算，點餐的人沒辦法自己改金額。
